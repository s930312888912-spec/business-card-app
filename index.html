✅ 安裝條件：需要用 HTTPS（例如 GitHub Pages / Netlify / Vercel）打開本頁，才會出現「安裝」或「加入主畫面」。

Android（Chrome）：打開頁面 → 右上角 ⋮ → 安裝應用程式 / 加入主畫面
iPhone（Safari）：打開頁面 → 分享按鈕 → 加入主畫面

你下載的檔案裡已包含：index.html、manifest.json、sw.js、icon 圖示。把整個資料夾上傳到任一個 HTTPS 靜態主機即可。
若你的瀏覽器支援，會顯示「安裝到桌面」按鈕。
🔒 資料儲存在你的手機本機（IndexedDB），不會自動上傳。
若你之後要「結合 GPT 自動辨識名片」，建議加一個後端（雲端函式）代理呼叫 API，避免把 API Key 放在前端。
